# Sorting Algorithm Visualizer

## Inspiration

I wanted to build something that leveraged the power of Matplotlib's graphing capabilities.  My goal was to visualize common sorting algorithms – bogo sort, bubble sort, insertion sort, merge sort, quick sort, and selection sort – to gain a deeper understanding of their inner workings and how they compare to one another. This project allowed me to explore data visualization techniques while reinforcing my knowledge of sorting algorithm complexities.


## Installation

Ensure you have Python installed on your system.  Next, install the necessary libraries: Matplotlib and NumPy.  You can do this using pip:  `pip install matplotlib numpy`

Clone this repository to your local machine using `git clone https://github.com/VanshAnand1/Sorting-Algorithm-Visualizer.git`. 
Navigate to the repository's directory in your terminal.

To run a visualization for a specific sorting algorithm, execute the Python script using `python3 filename.py` (replace `filename.py` with the actual name of the Python file for the algorithm you wish to visualize).  You can modify the constants within the script to adjust parameters such as the range of values, the number of items to be sorted, and other visualization settings.
